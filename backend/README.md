# @aksharmitra/backend

Shared data, content, and utility modules for AksharMitra.

## Modules
- \src/data/languages.js\ - Language configuration
- \src/data/translations.js\ - UI translations
- \src/data/letterHunterData.js\ - Letter Hunter game data
- \src/data/wordBuilderData.js\ - Word Builder game data
- \src/data/remediationData.js\ - Remediation activity data
- \src/data/demoProfiles.js\ - Demo learner profiles
- \src/streakUtils.js\ - Streak calculation utilities

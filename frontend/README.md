# @aksharmitra/frontend

React + Vite PWA app.

## Setup
\\\ash
npm install
npm run dev
\\\

## Structure
- \src/components/\ - UI components (auth, common, dashboard, landing, screening)
- \src/context/\ - React context providers (AudioContext, DyslexiaContext, ProfileContext)
- \src/games/\ - Game components (GamesHub, WordSnapper, LetterHunter, SpellingClinic, etc.)
- \src/screening/\ - Screening quest components
- \src/App.jsx\ - Root app component
